# Media MCP Studio 🎬🖼️

مشروع متكامل لتوليد ودمج الصور والفيديوهات بالذكاء الاصطناعي، مبني على **Next.js 15 (App Router)** وجاهز للاستضافة على **Vercel**، ويعمل كـ **MCP Server** (Model Context Protocol) يمكن ربطه بـ ChatGPT وأي عميل MCP، مع لوحة تحكم عربية وقاعدة بيانات **Turso**.

## المزايا

- 🖼️ **توليد الصور** عبر موديل `gpt-image-2-6/flare-text-to-image` من KIE.ai.
- 🎬 **توليد الفيديو (6 / 10 / 15 ثانية — افتراضي 15)** عبر موديل `grok-imagine-video-1-5-preview`، يدعم النص-إلى-فيديو والصورة-إلى-فيديو.
- 🧩 **دمج الفيديوهات**: يدمج من 2 إلى 10 روابط مقاطع بالترتيب في ملف MP4 واحد (H.264/AAC) عبر ffmpeg داخل الدالة، ثم يرفع الناتج إلى تخزين KIE ويُرجع رابطاً مباشراً دائماً.
- 🔑 **إدارة مفاتيح API متعددة** في Turso مع **تبديل تلقائي (Auto-Fallback)**: إذا نفد رصيد مفتاح أو رُفض، يُعلَّم «نفد رصيده» فوراً وينتقل النظام للمفتاح التالي بلا تدخل.
- 🗂️ **سجل كامل** لكل عميلة توليد/دمج في قاعدة البيانات مع روابط النتائج والحالة.
- 🤖 **خادم MCP** بنقطة Streamable HTTP (`/api/mcp`) ونقطة SSE القديمة (`/api/sse` + `/api/messages`).

## أدوات MCP الخمس

| الأداة | الوظيفة |
| --- | --- |
| `generate_image` | توليد صورة من وصف نصي (مع نسبة أبعاد اختيارية) وإرجاع رابط مباشر. |
| `generate_video` | توليد فيديو 6/10/15 ثانية من نص (أو من رابط صورة) وإرجاع رابط مباشر. |
| `merge_videos` | دمج 2–10 روابط فيديو بالترتيب في MP4 واحد وإرجاع رابطه المباشر. |
| `check_task` | متابعة حالة مهمة سابقة عبر `taskId` أو معرف السجل وإرجاع الروابط عند الاكتمال. |
| `list_media` | عرض أحدث السجلات مع روابطها. |

> ملاحظة: توليد الفيديو يستغرق عادة من دقيقتين إلى ثماني دقائق. إذا انتهى زمن الانتظار داخل النداء، تُرجع الأداة `taskId` ثم تكمل العملية في الخلفية ويمكن استدعاء `check_task` للحصول على النتيجة.

## النشر على Vercel (خطوة بخطوة)

1. ادخل [vercel.com/new](https://vercel.com/new) واختر استيراد مستودع `saaidrohim-jpg/media-mcp`.
2. لا تغيّر أي إعداد بناء — الإعدادات الافتراضية تكفي.
3. قبل الضغط على Deploy، افتح قسم **Environment Variables** وأضف المتغيرات من الجدول أدناه.
4. انشر، ثم اختبر: `https://<مشروعك>.vercel.app/api/health` يجب أن يرجع `{"ok":true,...}`.
5. افتح اللوحة على الصفحة الرئيسية وأضف مفاتيح KIE API (أو سيُزرع مفتاح `KIE_API_KEY` تلقائياً عند أول تشغيل).

### متغيرات البيئة

| المتغير | الوصف |
| --- | --- |
| `TURSO_DATABASE_URL` | رابط قاعدة Turso، مثل `libsql://media-db-saaid.aws-eu-central-1.turso.io` |
| `TURSO_AUTH_TOKEN` | توكن قاعدة Turso |
| `KIE_API_KEY` | مفتاح KIE افتراضي يُزرع في قاعدة البيانات عند أول تشغيل إذا كان جدول المفاتيح فارغاً (اختياري — يمكن الإضافة من اللوحة) |
| `KIE_BASE_URL` | `https://api.kie.ai` (افتراضي) |
| `KIE_UPLOAD_BASE_URL` | `https://kieai.redpandaai.co` (افتراضي — تخزين ملفات KIE للفيديو المدمج) |
| `KIE_IMAGE_MODEL` | `gpt-image-2-6/flare-text-to-image` |
| `KIE_VIDEO_MODEL` | `grok-imagine-video-1-5-preview` |
| `VIDEO_DURATION_SECONDS` | `15` (القيم المدعومة: 6، 10، 15) |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم (يُنصح بشدة بضبطها) |
| `MCP_SECRET` | سر نقاط MCP يُرسل في `Authorization: Bearer <MCP_SECRET>` (يُنصح بضبطه) |
| `IMAGE_WAIT_MS` / `VIDEO_WAIT_MS` / `MERGE_WAIT_MS` | أزمنة الانتظار داخل نداء MCP الواحد (افتراضي 110000) |

## ربط الخادم بـ ChatGPT

1. في ChatGPT: **Settings → Connectors / Developer mode → Create** (أو Apps → Advanced → MCP).
2. اختر **Custom connector** واستخدم:
   - النقل الحديث (الموصى به): `https://<مشروعك>.vercel.app/api/mcp`
   - أو النقل القديم SSE: `https://<مشروعك>.vercel.app/api/sse`
3. إذا ضبطت `MCP_SECRET` اختر مصادقة **API key** وضع قيمة السر (تُرسل في ترويسة Authorization كـ Bearer).
4. بعد الإضافة ستظهر الأدوات الخمس داخل المحادثة.

يعمل الخادم أيضاً مع أي عميل MCP آخر (Claude Desktop، Cursor، …) عبر نفس العنوان.

## نقاط الـ REST الخاصة باللوحة

| المسار | الوصف |
| --- | --- |
| `GET/POST/PATCH/DELETE /api/keys` | إدارة المفاتيح (عرض مبهمmasked، إضافة، تنشيط/تعطيل، حذف) |
| `GET/DELETE /api/media` | سجل الأعمال والإحصاءات |
| `POST /api/generate/image` | توليد صورة من اللوحة |
| `POST /api/generate/video` | توليد فيديو من اللوحة |
| `POST /api/merge` | دمج فيديوهات من اللوحة |
| `POST/DELETE /api/login` | دخول/خروج اللوحة |
| `GET /api/health` | فحص الحالة |
| `POST /api/mcp` | خادم MCP — Streamable HTTP |
| `GET /api/sse` + `POST /api/messages` | خادم MCP — نقل SSE القديم |

## كيف يعمل التبديل التلقائي للمفاتيح؟

عند أي طلب لمزود KIE، يقرأ النظام المفاتيح النشطة من Turso بترتيب إضافتها ويجربها واحداً تلو الآخر:

- استجابة `401/402/403/429` أو رسالة عن الرصيد/الصلاحية → يُعلَّم المفتاح `exhausted` ويُجرَّب المفتاح التالي فوراً.
- أخطاء الخادم (5xx) أو انقطاع الشبكة → يُجرَّب المفتاح التالي.
- أخطاء التحقق من صحة الطلب (مثل prompt فارغ) → تتوقف فوراً (لا علاقة لها بالمفتاح).

كل مفتاح يُسجَّل له عداد استخدام وإخفاقات ووقت آخر استخدام، ويمكن إعادة تنشيط أي مفتاح من اللوحة بعد شحن رصيده.

## حدود يجب معرفتها

- **مهلة دوال Vercel**: خطة Hobby تسمح بحوالي 60 ثانية للدالة، وPro تصل إلى 300 ثانية. الدمج الكبير وتوليد الفيديو يعملان بشكل أفضل مع خطة Pro أو عند تفعيل Fluid Compute. توليد الفيديو نفسه لا يتأثر لأنه يُدار كـ task لدى KIE ويُكمل في الخلفية.
- **الدُمج**: يُنزَّل كل مقطع (بحد 250MB لكل رابط) إلى `/tmp` ثم يُدمج ويُعاد ترميزه H.264/AAC — قد يستغرق ذلك دقائق للمقاطع الطويلة.
- **تخزين النتائج**: روابط الصور/الفيديو المولّد مستضافة لدى KIE، والفيديو المدمج يُرفع إلى تخزين KIE (`tempfile.redpandaai.co`) برابط دائم.
- **/api/sse** على المنصات اللاخادمية يعتمد على ذاكرة لكل نسخة function — إن لم تجد الجلسة افتح `/api/sse` من جديد، أو استخدم `/api/mcp` (الموثوق).

## الأمان

- لا تُخزَّن أي أسرار داخل الكود — كل شيء عبر متغيرات البيئة، والمفاتيح تظهر مُبهَمة (masked) في اللوحة.
- النشر الأول يكون المفتاح الافتراضي من `KIE_API_KEY`، ثم أضف المفاتيح الإضافية من اللوحة مباشرة.
- يُنصح بضبط `ADMIN_PASSWORD` و`MCP_SECRET` قبل فتح المشروع للعامة، لأن أي شخص يصل للوحة/النقاط المفتوحة قد يستهلك رصيدك لدى KIE.
- إذا تسرب أي توكن (Turso أو KIE أو GitHub) أعد توليده فوراً من لوحات الخدمات المعنية.
